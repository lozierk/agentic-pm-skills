# course-submission config

Course-specific values for the `course-submission` skill. Copy this file to `config.md` next to `SKILL.md`, fill in your own values, and leave the rest of the skill alone.

- **Author:** Your Name
- **Course folder:** `~/path/to/your/course/folder/`, one `Assignment_NN_*` subfolder per module. The local submission doc lives in that subfolder as `Assignment_NN_Submission.md`.
- **Notion project home (published, peer-facing):** the URL of the one page your weekly cover pages hang under
- **Google Drive course folder (archive only):** the folder id, one subfolder per assignment. Delete this line if you do not archive to Drive.
- **Maven course:** the course home URL, and the weekday your deadlines fall on.
- **Prior submission (format anchor):** path to last week's local submission doc. For week 1, point at any write-up whose shape you want to keep.
- **Cleared for peer-visible demos:** names and data you have decided may appear in public copies. Personal email addresses are never cleared.
